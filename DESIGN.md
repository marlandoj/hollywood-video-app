# Studio interface design

Register: product. A filmmaker reviews storyboard frames beside video footage at a desk;
the existing muted dark surfaces keep chrome quiet around the images. Preserve the current
OKLCH violet-neutral palette, single blue action accent, system font, and visible focus ring.

- One primary approval decision after storyboard and playback inspection.
- Storyboard images grouped by scene in disclosure sections; first scene opens initially.
- Horizontal shot strips within each scene, not an endless grid of identical cards.
- Text alternative on every frame; 44px disclosure targets and keyboard-native controls.
- Signed media URLs and provider details remain implementation concerns.
- Empty, queued, running, refused, cancelled and completed states use plain language.
- Reduced-motion preference affects UI transitions, never alters the film itself.
