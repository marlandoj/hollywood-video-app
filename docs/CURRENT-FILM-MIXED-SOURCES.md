# Completed mixed-film editorial sources

The internal `hv-edit-source/4` adapter exposes a completed V3 mixed film to source inspection, native editorial preparation and physical screenplay navigation. It preserves the target screenplay position separately from the original performance identity. A moved or reused line retains its original execution capture, render record and native speech samples.

Inspection validates the complete completed job and its prepared proof, measures the actual target-owned files, and records the HLS playlist's exact ordered segment inventory. Retained roles are streamed with bounded reads and checked digests. A receipt is historical evidence; current project, cast and reference grants, source availability and actual media access remain separate checks.

Dialogue preparation places each retained mono 22,050 Hz waveform at its target film position before one global conversion to stereo 48 kHz. Editorial clips and speech navigation use this global clock. Native checks compare decoded picture, PCM and captions after trimming and reordering, including operation with the original owner directories hidden. A resealed receipt or normalized file cannot substitute for independent media verification.

Caption correspondence requires the entire ordered caption set to match. A changed, missing, reordered or renamed cue leaves caption navigation unbound while measured speech retains its independently established windows. Duplicate text is addressed through physical line identity rather than text search.

Historical metadata acceleration retains full portable-input keys and detached return values. Completed-source and clock validation have separate contracts: a strict editable source requires its actual prepared proof; the historical clock continues to support the earlier unmarked metadata contract. Bounded caches do not retain successful current permission checks. Altered serialization intrinsics use the original cold validation path, and mutable clock limits remain enforced.

Public persistence is a separate boundary. The current saved library and API refuse unsupported `/4` publication. Library version 2, state schema 16, public save/restart, approved-final proof ownership and carrier-only recovery are being qualified separately. V3 films are not accepted as generation origins through the strict V2 origin contract.
