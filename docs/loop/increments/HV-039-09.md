# HV-039-09 — Choosing a take to compare stopped it within two seconds while another read rendered

epic: HV-039
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0

## Why

The voice studio's **Compare saved takes** redraws only when its signature changes. That signature
includes which take each slot shows:

```js
const signature=()=>JSON.stringify({jobs:…,comparison});
if(signature()===historySignature)return;historySignature=signature();stopMedia();history.replaceChildren(…);
```

Choosing a take in slot A or B changed `comparison`, but `historySignature` was not updated. While
any read for the line is queued or rendering, the studio checks every two seconds. The next check
found a signature that no longer matched and redrew. `stopMedia()` paused every take and removed its
source, and both slots were rebuilt.

A creator who picked an earlier take for B and pressed play heard it stop within two seconds. Focus
left the list they had just used. The same thing happened each time they chose again, for as long
as the new read was rendering. Comparing reads is what this panel is for, and new reads are
generated while the creator is comparing.

## What this increment does

- **The signature moves with the choice.** When a slot's take changes, its signature is recorded,
  so the next status check redraws only if the reads themselves changed.

## Acceptance criteria

1. **A take chosen for comparison keeps playing through the next status check.** No take is
   stopped, the slot's list is the same element with the same value, and the chosen take's audio is
   still on the page.
2. **A read that does change is still redrawn**, and the take the creator chose stays chosen.
3. Reverting `audio-studio.js` fails criterion 1.

- Tests: `packages/frontend/test/audio-comparison-poll.test.js`, with the two-second check run by
  hand and `<audio>` elements that record being paused.

## Known gaps this leaves

- **A read that finishes still redraws both slots and stops what is playing.** That redraw is
  needed to show the new take. Updating only the slot that changed is a larger change.
- **Signed URLs expire.** **Refresh saved takes** still redraws everything, on purpose, to replace
  expired links.
