# HV-024-08 — "Load sound session" with no available cut read the catalogue as a quote

epic: HV-024
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0

## Why

Opening the sound session lists every retained cut under **Picture or sound version**. Cuts that
are no longer retained are listed but disabled. When none is available, the select's value is `""`:

    choose.value=data.sources.filter(s=>!s.unavailable).at(-1)?.id??"";
    …controls.append(button("Load sound session",()=>inspect(choose.value)),…

**Load sound session** stayed enabled anyway, and `inspect("")` asked for `request("/"+id)`, which
is `/sound-mixes/`. The API drops empty path parts, so that request returns the catalogue listing.
The panel took the listing for a quote:

- it hid any sound version the owner had open;
- it cleared the editor;
- it showed a raw TypeError, such as *"undefined is not an object (evaluating
  'quote.durationSec.toFixed')"*.

The panel had already told the owner, correctly, to create a retained film with isolated voices.
The button then offered to do something it couldn't do.

## What this increment does

- **Load sound session is disabled while no available version is chosen.** That covers the case
  where every cut is unavailable and the case where there are no cuts.
- **`inspect` refuses an empty id** before it touches the playback or the network. It says
  *"Choose an available picture or sound version before loading a sound session."* This catches a
  click that reaches the handler anyway.

## Acceptance criteria

1. **With every retained cut unavailable**, the select's value is empty and **Load sound session** is
   disabled. The existing "Create a retained film…" guidance still shows.
2. **With no retained cut at all**, **Load sound session** is disabled.
3. **With an available cut**, the button is enabled and loads that cut's quote, as before.
4. **Loading with no chosen version** makes no `/` request and shows the sentence above as an error.
5. **Loading with no chosen version** leaves an open sound version on screen.
6. Reverting `sound-studio.js` fails criteria 1, 2, 4 and 5.

- Tests: `packages/frontend/test/sound-load-no-source.test.js`.

## Known gaps this leaves

- **The API still answers `GET /sound-mixes/` with the catalogue.** A client that sends an empty id
  gets a 200 rather than a 404. Only this panel sent one, and it no longer does.
- **Lip-sync's Load applied lines** already disables itself with no eligible source. Dialogue
  replacement only draws its source list when a cut is eligible. No other panel was found with the
  same shape.
