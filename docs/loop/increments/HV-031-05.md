# HV-031-05 — Four ways past the safety gate

epic: HV-031
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0

## Why

A critic pass over `packages/safety` and the cast record that feeds it looked for ways past the
gate rather than for ways to describe it. It found four, and none of them needed anything the
studio does not hand out for free.

**1. A character that is not there.** `foldForMatching` lower-cased and stripped accents. A
zero-width space, a zero-width joiner, a soft hyphen, a word joiner and a BOM are `\p{Cf}`: they
survive NFKD, are not `\s`, and are not combining marks, so they were in none of the three things
the fold removed. Inserting one after the first letter of each word carried **seventeen of the
seventeen prompts in this package's own battery straight through**, allowed, with no category and
no log line. The text renders unchanged to a person and tokenizes to the same thing for a provider;
the refusal was the only thing that saw a difference. The repository already knew this —
`motion-graphics.ts` refuses `[\p{Cc}\p{Cs}\p{Cf}]` in every string a title carries, and so do the
graphic library and the composite plans — but the knowledge never reached the gate.

**2. A letter that is not the letter it is drawn as.** A Cyrillic `а` and a Latin `a` are different
code points with the same glyph. "Tаylor Swift" was not on the list and reads to a person as
the name.

**3. A string long enough to stop the server.** Six of the prohibitions were written
`A[\s\S]*B` — "A appears, then anything, then B". That is quadratic when A matches in many places
and B never does: the engine rescans the whole tail from each A. Measured on the minor/sexual pair,
with the word "teen" repeated — benign English, correctly allowed:

| characters | one pattern |
| --- | --- |
| 12,500 | 34 ms |
| 25,000 | 147 ms |
| 50,000 | 519 ms |
| 100,000 | 2,063 ms |
| 200,000 | 8,135 ms |

Fourfold per doubling. One `checkPrompt` runs every pattern twice, over the raw text and the folded
one, and the whole call took **21.5 seconds** at 199,950 characters. That is the script route's own
size limit, and `crew/read-through.ts` hands `checkPrompt` the entire script in one call. On a
single-threaded server that is the event loop, not a worker: every other request waits. The route
needs no project token and no provider key.

**4. And the cast record read a quarter of itself.** `characterRecord` checked `name`, the aliases
and `appearance` against the public-figure list. `describeCharacter` puts all twelve described
fields and every wardrobe description into the shot prompt. A listed figure written into
`hairMakeup` saved clean and was refused at generation — after the creator had committed to the
film, with a message that names no field.

## What this increment does

- **The fold strips `\p{Cf}`, `\p{Cs}` and `\p{Co}` as well as combining marks**, and maps the
  common ASCII-colliding Cyrillic and Greek letters back to the Latin letters they are drawn as
  (thirty-four entries, thirty-one of them letters; a list of thirty is worth having and is not a
  claim that the gate is Unicode-complete, which `PUBLIC_FIGURES`' own note already denies). Case
  is folded *before* the homoglyphs are, so a capital Cyrillic Е is the same table entry as its
  lower-case form — the other order missed every name written in capitals, which is how a character
  cue is written.
- **`A[\s\S]*B` becomes two searches AND-ed.** `SafetyPattern` is now `RegExp | {every: RegExp[]}`
  and `both(A, B)` builds the pair. "A appears somewhere and B appears somewhere" is exactly what
  the old pattern meant, so the refusal neither grows nor shrinks — which matters, because bounding
  the gap instead would have shrunk it. The same 199,950-character string now measures **6 ms**.
- **Every free-text field of a cast record is read at the save**: the twelve described fields, the
  aliases and every wardrobe description — the same text the prompt carries. The text is assembled
  by `castRecordText`, derived from `TEXT_LIMITS` rather than listed by hand, so a thirteenth field
  is covered the day it is added.
- **A stored record is still not re-judged**, and that is deliberate rather than an oversight. The
  list only grows; a name added tomorrow must not make a cast saved today unreadable, because the
  studio would then refuse to *open* the project rather than refuse to render it. The prompt gate
  still refuses every shot that carries the name, so such a record can be read and edited and cannot
  be filmed.
- **An actor import is a save, not a read.** `importedActor` must build a stored record — it carries
  costume presets and a library origin, which only a stored record may hold — so `characterRecord`
  would never have looked at its text. It reads it itself, at the border, including the costume
  preset descriptions, which were copied out of a share's wardrobe and had been read by nothing.

## Acceptance criteria

1. **No prompt in the battery passes with an invisible character in every word**, for each of six
   `\p{Cf}` characters, and each is refused under its own category rather than merely refused.
2. **A benign prompt laced the same way is still allowed**, so the fold only ever added refusals.
3. **A name written with Cyrillic or Greek homoglyphs is refused**, in lower case and in capitals,
   and with an invisible character as well.
4. **Ordinary text is unchanged by the fold** — "Taylor walks swiftly", "café" — and `foldForMatching`
   is asserted directly, not only through a verdict.
5. **199,950 benign characters are judged in under a second** (measured: 6 ms).
6. **The pair still refuses however far apart the two terms fall**, in either order, and neither term
   alone is a refusal.
7. **No prohibition pairs two terms with an unbounded gap**, asserted over the source text of
   `PROHIBITIONS`, because it is a shape one new line can reintroduce.
8. **Every free-text field of a cast record refuses a listed figure**, iterated over the record's own
   string fields rather than a hand-written list, plus the wardrobe and the aliases.
9. **A clean record still saves**, so nothing was refused that should not have been.
10. **An import carrying a listed figure in a costume preset is refused**, and a clean share still
    imports with its presets intact.
11. **A saved record is still readable** (the existing test, unchanged, which is what this increment
    had to be built around).

- Tests: `packages/safety/test/safety.test.ts` (1–7), `packages/planner/test/consented-casting.test.ts`
  (8–11).

## Known gaps this leaves

- **This is still a keyword list.** Nothing here makes it a semantic or multilingual moderation
  system, and the standing note in `docs/CASTING.md` — that reliable detection of named real people,
  likeness abuse, minors and paraphrases needs a separate evaluated system before public launch —
  is unchanged. Four holes closed is four holes closed.
- **The homoglyph table is thirty-four characters**, chosen from Cyrillic, Greek and the IPA
  extensions where the glyph collides with ASCII. A full Unicode confusables table would be a
  dependency and a much larger claim; this is the common case, written down.
- **Mixed-script text is folded, not refused.** Refusing any name written in two scripts would be a
  stronger rule and would also refuse legitimate text; it was not taken, and is a decision for the
  moderation review rather than for a build session.
- **The quadratic was fixed where it was measured.** `packages/planner/src/crew/production-plan.ts`
  calls `checkPrompt` up to three times per character record, and the other callers listed in
  `grep -rl gateOrThrow packages/*/src` were not individually timed. They are all linear now because
  the patterns are, but no test asserts a bound on any route.
- **No route-level test.** The 21.5 seconds was measured on `checkPrompt` directly, not by holding a
  server's event loop and watching a second request wait. A test that did that would be timing-
  dependent in CI.
