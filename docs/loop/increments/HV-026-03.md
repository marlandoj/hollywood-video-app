# HV-026-03 — The quality check is something an operator can run

epic: HV-026
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0 — ffmpeg only, on a file that already exists.

## Why

HV-026-01 built the check and said plainly that nothing called it. HV-026-02 ran it once against a
real film — **by hand, from a build session**, which is exactly the shape of thing that stops being
true the moment the session ends. The measurement that found illegal luma in the delivered master
lived in my terminal and nowhere else.

The creator-facing wiring is a larger piece of work: a deliverable belongs to a job, a job's artifact
set is sealed by design, and a route that measures an object in the store has to fetch it, bound its
concurrency and answer through the permission surface. None of that is needed for the operator, who
already has the file.

## What this increment does

- **`scripts/picture-qc.ts`** measures a master and prints what it found: the programme's facts,
  every finding with its severity, the verdict, and — **every time it runs, not only in the
  documentation** — what it did not look at.
- **The exit code is the verdict**: 0 when nothing above a note was found, 2 when a person should
  look, 1 when the check could not run at all. A shell can tell "nothing to look at" from "look"
  without parsing anything, which is the difference between a check that can sit in a pipeline and
  one that cannot.
- **`--out` writes the full report**, and that file is re-derived from its own measurement when it is
  read back, so a finding or verdict edited under a kept revision is refused.
- It needs **no project token and no provider key**, because the check touches neither, and it writes
  nothing except what `--out` names.

## Acceptance criteria

1. **A finished film measures clean and says so**: the programme's size, rate, pixel format, codecs,
   sample rate and channels are printed, the verdict is `pass`, and the exit code is 0.
2. **A black, frozen, silent film reports what to look at** — the black and frozen warnings by name —
   with verdict `review` and exit code 2.
3. **The report it writes is still the contract's own**: read back, it re-derives from its own
   measurement and validates.
4. **What it did not check is printed on every run.**
5. **It refuses what it cannot measure on its own exit code**: a missing file, a file that is not a
   film, and a missing argument each exit 1 with a message on stderr and nothing on stdout.

- Tests: `packages/generator/test/picture-qc-script.test.ts`, which spawns the script.

## Known gaps this leaves

- **The creator still cannot run it.** A route that measures a finished job's delivered master,
  fetching it from the object store under the permission surface, is the next increment, and it is
  the one that needs the job-stage work HV-027-01 also waits on.
- **Nothing runs it automatically.** No job, worker or deployment step calls the check; an operator
  runs it when they want it.
- **The illegal luma range HV-026-02 found is still not fixed**, for the reason recorded there: it is
  a render-path change that has to meet the conform's bit-exact standard.
