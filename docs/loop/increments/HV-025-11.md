# HV-025-11 — A graphic is checked like any other original

epic: HV-025
release: 1 "Studio" (closing gap), carried into 2
gate: none new
spend_usd: 0

## Why

With HV-025-09's render deadline and HV-025-10's check allowance both in place, the short's title
pass failed again, in the same shape and for a reason of my own making:

```
/api/projects/:id/editorial/sources/:id -> 400 The operation timed out.
```

The API's own log shows that request took **30.4 seconds**, not the allowance the film's frames earn
it. Thirty seconds is the deadline on one specific path: HV-025-07 added a fast refusal for a job
with nothing retained to check —

```ts
if (!job.output) return { …await this.binding(…, AbortSignal.timeout(30_000)) };
```

— and a graphic does not keep its media in `output`. A motion-graphic job keeps it in
`graphicOutput` (`editSourceOutputRevision`, `editSourceRequiredPaths` and the rest of the editorial
code read either). So every graphic went down the refusal path and was checked synchronously with a
thirty-second deadline. CI never saw it: its graphics are six and twelve frames and check in well
under thirty seconds, while the title and credits the Editor renders are 120 and 180 frames.

## What this increment does

- The fast refusal now applies only when a job has **neither** `output` nor `graphicOutput` — that
  is, when there is genuinely nothing retained to check.
- The cache key and the finished-check lookup use `editSourceOutputRevision`, the function the rest
  of the editorial code uses for exactly this question, so a graphic's retained media keys the same
  way a film's does.

## Acceptance criteria

1. **A graphic is checked in the background like any other original**: the first call for a rendered
   motion graphic answers 202, then the receipt, with `media: "graphic-rgba"` — it is not pushed
   down the refusal path with its thirty-second deadline.
   - Test: `packages/api/test/graphics.test.ts`, "owners use a graphic in saved-cut PNG preview and
     keep editing from an independent retained alpha copy" (CI's graphics job).
2. **Nothing else changes.** The inspection, inspection-reuse, editorial and graphics suites pass
   unchanged.
