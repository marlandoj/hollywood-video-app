- HV-019-18: two same-day merges broke shot planning.

This increment is that run: "The Tide Clock" (`docs/evidence/release-3/scripts/feature.fountain`, 34 scenes, 202 shots, 10 sequences) goes through the studio at the front door. ## What this increment does

- **The host is set for the run:**

  - `HV_ROUTING_STRATEGY=quality`;
  - `HV_ROUTING_QUALITY_RESULTS_PATH=docs/evidence/release-3/benchmark/routing-results.json`.
- **The run follows HV-030-31's runbook, steps 1–8**, with `--spend-declared 135`. Between sequences the spend lines are read. The run stops if the generation line's spend passes $100 before the last sequence.
- **Deferred parts:** `HV-019.second-vendor` and `HV-020.native-camera`, both to G21-202610041254.
- **The record and its test** are added to this branch once the run and the review are done. The record is never edited to pass. A failing criterion is fixed, or the run is redone.
