# HV-029-11 — Revoking a review link left the media links it had handed out working

epic: HV-029
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0

## Why

Opening a review link returns signed media URLs: the MP4, the HLS playlist and its segments, and the
captions. They are valid for as long as the link (HV-029-05). Those URLs were ordinary artifact
links that named only the project, the job and an expiry. HV-029-08 gave the owner a way to withdraw
a link, and after that the review page answered 403. The artifact route, though, checks only the
signature, the project's deletion date, takedown and cast permission. So the MP4 the reviewer had
been given still downloaded for up to seven more days. Withdrawing the link did not withdraw the
film.

## What this increment does

- **A media link handed out by a review link names that link.** It carries the SHA-256 digest of
  the review token (`review`), not the token itself, so the media URL never carries the credential
  that opens the page and records decisions.
- **The artifact route refuses a link whose review link is revoked or gone** (404).
  `ProjectService.reviewLinkWithdrawn` and `PostgresProjectService.reviewLinkWithdrawn` answer this,
  looking only at the media's own project.
- **The token verifier accepts the extra `review` key** only on an artifact token, and only as a
  64-hex digest.
- **The owner's own media links name no review link** and are unchanged.

## Acceptance criteria

1. **Revoked link.** After the owner revokes a review link, the MP4, HLS and caption links it handed
   out answer 404.
2. **Other links unaffected.** Another review link's media, and the owner's own media, keep working.
3. **Digest, not token.** A media link names its review link by digest, never by the token. A
   malformed `review`, or a `review` on another kind of token, is refused.
4. **PostgreSQL.** A revoked or unknown link is withdrawn, and a live one is not. A link of another
   project does not vouch for this project's media.
5. Reverting the source files fails criteria 1–4.

- Tests: `packages/api/test/review-revoke-media.test.ts`, and
  `packages/storage/test/review-withdrawn.test.ts` (PostgreSQL-gated; run against a local
  PostgreSQL 16).

## Known gaps this leaves

- **Media links handed out before this change** carry no review link, so revoking their link
  doesn't reach them. They expire with the link, as before.
- **Each request looks the link up.** Every request for a reviewed media link, including each HLS
  segment, loads the project's review links. Projects hold few links.
