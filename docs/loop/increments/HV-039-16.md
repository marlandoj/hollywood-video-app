# HV-039-16 — The voice studio, the graphics desk and take comparison closed onto the page body

epic: HV-039
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0

## Why

HV-039-05 and HV-039-06 made the cast and shot-direction desks give focus back to the button that
opened them when they close. Three more panels still hid themselves while focus was inside them:

| Panel | Close control | What it ran |
|---|---|---|
| Voice studio | **Close voice studio** | `close()`, which is `panel.hidden=true`. The page's "Save screenplay and audition voices" button was never focused again. |
| Titles and graphics desk | **Close graphics** | `cancelView();panel.hidden=true;` |
| Take comparison (opened from a shot's "Compare takes for s3" in the direction list) | **Close take comparison** | `player?.pause();panel.hidden=true;clearTimeout(timer);` |

Hiding an element that holds focus drops focus to the page body. A keyboard or screen-reader user
who closed any of these panels had to start again from the top of the page.

## What this increment does

- **Each panel remembers where focus was when it opened**, if that was outside the panel. Closing
  it focuses that control again, provided the control is still on the page and enabled.
- The voice studio's `close()` also runs on `pagehide`. That path does not move focus; only the
  Close button does.

## Acceptance criteria

1. **Closing the voice studio returns focus to the button that opened it.**
2. **Closing the graphics desk returns focus to the button that opened it.**
3. **Closing take comparison returns focus to the shot's Compare takes button.**
4. **An opener that is gone by the time the panel closes is not focused.**
5. Reverting the three files fails criteria 1–3.

- Tests: `packages/frontend/test/desk-close-focus.test.js`.

## Known gaps this leaves

- **The sound session and picture editorial** close the same way ("Close sound session", "Close
  picture editorial"). Each needs its own mount in a test and is not changed here.
- **Subject motion's "Discard movement draft"** hides its panel as well.
