# HV-017-08 — "An older woman" and "a middle-aged man" are read correctly

epic: HV-017
release: 1 "Studio"
gate: G13-202609192200
spend_usd: 0

## Why

The release-run scripts showed two misreadings in the stand-in crew's casting (HV-017-05):
- "RUTH, an older woman" gave no age, because "older" was not in the age table.
- "TOMAS, a middle-aged man" was cast as an older adult, because "aged" matched.

## What this increment does

- "older" now reads as an older adult.
- "middle-aged" is removed before the age words are read, so it states no age from the table. The character is cast with an unstated age.

## Acceptance criteria

1. "An older woman" gives female and older adult.
2. "A middle-aged man" gives male with no age.
3. "An aged sailor" still gives older adult.

Test for all three: `packages/planner/test/crew-introductions.test.ts`.
