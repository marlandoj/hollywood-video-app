# HV-026-01 — A delivered film is measured, and the measurement is the evidence

epic: HV-026
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0 — ffmpeg only, on the machine already running. No provider is called.

## Why

HV-026 has no code, no docs and no increments. Its Release 2 slice is "Grade and LUTs, QC checks.
ffmpeg only", and of those two halves the QC half is the one that can be built honestly first, for a
reason worth writing down: **measurement changes nothing.** The picture path hashes every frame and
refuses any change it did not plan for — `accurate_rnd+bitexact` on every scale, `-threads 1`
everywhere, fixed-point Rec.709 coefficients in the composite recipe — so a grade is a new
deterministic filter stage that must be specified to that standard. A check that only reads the file
cannot move a frame hash at all, and it can ship today.

It also closes a gap that is easy to miss. `docs/evidence/release-2/elevenlabs-voiced.json` records
`"meanVolumeDb": -29.7, "maxVolumeDb": -3.4`, and `release-1/live-reel-voiced.json` records the same
pair — **and no product code produces those numbers.** They are measured by hand with
`ffmpeg -af volumedetect` inside three test files and transcribed into the evidence. A number that
appears in release evidence should come from code that can be run again.

## What this increment does

- **`packages/planner/src/picture-qc.ts`** — the contract: `PICTURE_QC_RECIPE` with every filter
  string and every threshold declared once, the measurement and report shapes, the pure
  `pictureQcFindings`, and `validatePictureQcReport`.
- **`packages/generator/src/picture-qc.ts`** — `measurePictureQc`: one `ffprobe` and one decode
  through `blackdetect`, `freezedetect`, `signalstats` and `volumedetect`, on the bounded subprocess
  runner the sound path already uses, with its lease checks, cancellation and diagnostic limits. It
  writes nothing beside the film and removes its own scratch.
- **Eleven findings over three severities**, decided by one threshold table: a **fail** is a film
  that cannot be delivered as it is (no audio, silence, clipping), a **warning** is something
  measured that a person has to look at (black, freeze, illegal levels, a mix well outside the range
  finished films have measured here), and a **note** is worth saying and not a reason to stop.
- **The report says what nobody looked at.** `notChecked` is part of the report, not of the
  documentation, because a check that lists only what it found reads as a clean bill of health.
- **A retained report is re-derived from its own measurement** — the whole report, not its revision,
  so a kept revision cannot vouch for findings edited under it. (The test for this found that
  comparing revisions alone did exactly that.)
- **`docs/PICTURE-QC.md`**, ending in what this does not establish.

## Acceptance criteria

1. **Every threshold has its own finding, at its own severity**, and a finished film's measurement
   produces none of them: no audio, end-to-end silence and clipping are fails; quiet, loud, black,
   frozen and illegal levels are warnings; an unexpected frame rate or pixel format, and levels that
   could not be measured, are notes.
2. **The verdict is `pass` only when nothing above a note was found.** A report carrying only notes
   passes.
3. **A finding names what it measured** — a black span carries its times in the message and as data —
   and the report carries the list of what was not checked.
4. **A retained report is re-derived before it is believed**: editing a finding, a verdict or a
   measurement under a kept revision is refused, and a report from another recipe revision is
   refused rather than reinterpreted.
5. **It measures a real film.** A generated three-second film is measured end to end: the container
   facts come back, every frame is sampled for levels, the sound levels are real numbers, and the
   verdict is `pass`. A black, frozen, silent film of the same length is `review`, with the black and
   freeze spans and their times, and a freeze running to the end closed at the programme's duration.
6. **Measuring changes nothing**: measuring the same file twice produces the same report revision,
   and no file is written beside the film.
7. **Nothing else changes.** No render path, recipe or frame hash is touched; the generator, planner
   and editorial suites pass unchanged.

- Tests: `packages/generator/test/picture-qc.test.ts` (1–6).

## Known gaps this leaves, stated rather than implied

- **Nothing calls this yet.** The check is a function and its contract; wiring it to a delivered
  job — where it runs, who sees it, and whether a `review` verdict blocks anything — is the next
  increment, and deliberately separate because it touches the finishing path this one does not.
- **No colour of any kind.** No grade, no LUT, no colour management, no transform. P11's `grade`,
  `lut` and `look_lock` objects are untouched, and a grade has to meet the render path's bit-exact
  standard, which is a larger piece of work than this one.
- **These are house thresholds, not a delivery specification.** The −45/−12 dB bounds are the range
  finished films have actually measured in this project. Broadcast loudness is measured properly and
  separately in `docs/SOUND-FINISHING.md`, and this check neither repeats nor replaces it.
- **Safe area, caption overflow, decodability across players, colour accuracy and HDR are not
  checked**, and the report says so in every copy of itself.
