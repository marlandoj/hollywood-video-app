# HV-030-21 — The plan step checked each answer alone, then sent them to the crew model together

epic: HV-030
release: 2 "Voice and crew depth"
gate: none new
spend_usd: 0

## Why

The prompt gate's paired rules (FR-054: minor terms beside sexual terms) apply to a request as a
whole. `planInput` put the tone and each question, proposal and reply through the gate one string at
a time. `runPlan` then sent all of them to the model in one prompt, beside the script. A tone of
"Tense, with teenagers" and a reply of "explicit nude close-ups" each passed on their own, and
reached the paid crew model together. Shown side by side, the gate refuses that request.

HV-030-19 closed the same gap for the read-through. The review of that increment found this older
one in the plan step, which dates from HV-030-02.

## What this increment does

- **Answers are checked together.** `planInput` checks the tone and every question, proposal and
  reply as one text. If they fail together, the route answers 400, *"…nothing was sent to the
  crew"*.
- **The whole prompt is checked.** `runPlan` checks the prompt the model would receive, with the
  script and the answers side by side, before anything is spent or sent. If it fails, the stand-in
  plans (`fallbackReason: "content_policy"`) and the model is asked nothing. The stand-in plan does
  not read the answers.
- Safety refusals only grow.

## Acceptance criteria

1. **Answers that fail only together.** A tone and a reply that each pass alone are refused together,
   with nothing sent.
2. **Answers that fail only beside the script.** Answers that pass together but not beside the script
   are planned by the stand-in, with `content_policy` given as the reason, $0 spent, and the model
   asked nothing.
3. **Ordinary answers** still reach the crew model.
4. Reverting `production-plan.ts` fails criteria 1 and 2.

- Tests: `packages/planner/test/crew-plan-whole-request.test.ts`.

## Known gaps this leaves

- **The refusal doesn't say which pair of answers tripped it**, like the gate's other refusals.
