# HV-025-10 — Checking an original is allowed time in proportion to the film

epic: HV-025
release: 1 "Studio" (closing gap), carried into 2
gate: none new
spend_usd: 0

## Why

The Release 1 short still could not be titled. With HV-025-09's deadline in place, the title pass
reached the source check and this came back:

```
/api/projects/:id/editorial/sources/:id -> 400 The operation timed out.
```

HV-025-07 gave the background check a fixed fifteen minutes. That was a guess, and the measurements
say why it is the wrong shape:

| What | Time |
|---|---|
| Reading the film's 28 MB export from the object store | 53 ms (531 MB/s) |
| `ffprobe -count_frames` over its 1,500 frames | 1.7 s |
| The whole check, host quiet (HV-025-07's first run) | 340 s |
| The whole check, host busy | over 900 s, abandoned |

The object store is not the bottleneck and neither is the probe. The cost is `inspectEditSource`
reproducing the source's own conversions: for a sound mix that is `verifySoundMedia`, which
re-derives the mix from its stems, re-measures its loudness and re-runs its delivery master. That
work grows with the film and with what else the host is doing, and a fixed allowance cannot cover
it.

## What this increment does

`editInspectionTimeoutMs(frames)`: 60 s plus 1 s per frame, never below the old fifteen minutes and
never above an hour, and never more than the render deadline for the same film. `EditApi` gives each
background check that allowance from the source job's own frame count.

The check itself is unchanged — same files, same reproduction, same refusals. This is only how long
it may take before it is abandoned.

Making the check *cheaper* is the next increment: a sound mix that the worker already verified
under this exact runtime revision, whose bytes are proven identical by checksum, is being re-derived
from scratch every time the film is used as an editorial source.

## Acceptance criteria

1. **The allowance comes from the film.** Zero frames and a fifteen-second reel keep the
   fifteen-minute floor; the fifty-second short gets base plus a second a frame; a feature-length
   source stops at the one-hour ceiling; a fractional or negative frame count is refused.
2. **A check never outlasts the render it prepares for**, at any length.
3. **A bad frame count is refused** rather than silently treated as zero.
   - Tests for all three: `packages/generator/test/edit-resources.test.ts`.
4. **Nothing else changes.** The editorial and inspection suites pass unchanged.
