# Current screenplay state and film inputs

The canonical screenplay library persists an immutable original, saved structural proposals, accepted history and an explicit head. Each accepted state includes the complete current document and shot plan, line direction, cast correspondence and its reviewed origin. A saved proposal leaves the committed screenplay unchanged.

The internal project service establishes the original only against an exact current script/cast/direction baseline and an available original-film carrier. It checks present project rights, character permissions and the reference catalog against every effective shot. Structural acceptance publishes all intermediate screenplay versions, candidate casting and the accepted library head in one detached state write. PostgreSQL performs the same operation under the project lock. Exact retries return the saved result without another write; a direct script or legacy-direction edit requires explicit reconciliation before a new structural acceptance.

The current-film V2 compiler resolves the complete accepted head or saved proposal from its frozen library. Every active logical shot has one ordered input with its original render identity or explicitly allocated new identity, effective shot, physical line membership, shared provider recipe and exact input revision. Requested generation frames are distinct from measured output frames. This first runtime input implementation selects fresh generation for every slot. It does not claim media reuse or actual dispatch.

State schema 12 preserves the canonical library and every accepted script version. Recovery rejects older schema declarations, unowned nested markers and inconsistent ancestry. The Python archive verifier delegates complete historical validation to the application and independently verifies retained original media. Current permission decisions are made again after restoration.

These internal services are not yet exposed as a complete structural editing workflow. Remaining integration includes canonical queue/worker admission and checkpoint/output adapters, current provider/approval/cost fences, immutable-source versus current-target reuse bindings, measured picture/speech/caption clocks, reverse cut-to-script acceptance, the subsequent forward edit and owner comparison/export. Linked cut acceptance must publish its independent cut/history in the same transaction; the current script-only internal operation does not substitute for that contract. Explicit reconciliation of orphaned cast settings, new artistic settings and branch/merge workflows also remains.
