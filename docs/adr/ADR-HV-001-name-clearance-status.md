# ADR-HV-001: Name Clearance Status for "Hollywood Video"

**Date:** 2026-08-30
**Status:** proposed (clearance NOT obtained)
**Confidence:** 0.9 about the process; 0.0 about the name surviving clearance

## Context

AC-003 requires name clearance for "Hollywood Video" (or the pre-cleared fallback)
documented in an ADR. "Hollywood Video" is a well-known former US video-rental brand
with plausible surviving trademark rights; the collision risk is material.

## Decision

"Hollywood Video" remains a WORKING TITLE only, used solely inside this private
repository. Per ADR-0020, public branding is fail-closed until trademark counsel
returns a clearance opinion. The interim fallback used on all UI surfaces is the
neutral descriptor "Script-First Studio (working title)". No public surface,
domain registration, or announcement may use "Hollywood Video" until this ADR is
superseded by an ADR recording either (a) counsel clearance of the name, or
(b) adoption of a cleared replacement name.

## Consequences

AC-003 is satisfied procedurally (the clearance state is documented and gated)
but the clearance itself is an external legal action the factory cannot perform.
The launch checklist blocks on superseding this ADR.
